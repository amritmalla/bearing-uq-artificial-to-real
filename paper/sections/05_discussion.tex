\begin{itemize}[nosep]
  \item Why thresholds fail: for the silent bearings the fault-frequency signature is weak or absent, so the model is
        confidently wrong; calibration fitted on artificial data cannot see this.
  \item Calibration on artificial bearings does not transfer: in-domain ECE 0.01--0.09 vs 0.17--0.20 on real damage.
  \item Conformal prediction: the shift breaks exchangeability; class-conditional conformal did not help here,
        unlike the class-proportion mismatch case in \citet{gonzalezgarcia2026}.
  \item Recommendations for practice: calibrate and set thresholds on labelled real bearings; expect lower
        automation; report results per bearing.
  \item Feature lesson: absolute-amplitude features describe individual bearings rather than damage.
\end{itemize}
